# 灵境童创 APP 可点击原型

灵境童创是一款面向 3–8 岁儿童的实体互动故事积木产品。本仓库保存配套 APP 的高保真交互原型。

## 体验地址

发布后可通过 [GitHub Pages](https://hotreport.github.io/lingjing-tongchuang-app/) 打开。

## 原型流程

- 家长登录、连接底盘、检查并升级软件、选择故事、同步信息到底盘，再开始搭建。
- 故事搭建支持积木感应、多角色识别、角色位置关系判断和 AI 故事互动。
- 摄像头玩法可单独开启；首次使用包含配对引导。
- 商城支持底座、故事包、摄像头单买或优惠组合，并依据演示订单生成补购积木清单。
- 故事结束后生成六维成长观察报告，并展示明确标注的同龄演示参考。

## 运行

```bash
npm ci
npm run dev
```

推送到 `main` 分支后，GitHub Actions 会构建并发布 GitHub Pages。

## 原型说明

底盘连接、软件升级、故事同步、摄像头配对、订单与结算均为交互演示。成长报告记录故事中的可观察互动；同龄比较使用明确标注的演示数据，不代表真实样本、标准化量表或诊断结果。
